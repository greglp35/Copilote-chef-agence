# SPEC-KIT-WEB-STARTER

Starter neutre et adaptatif pour projets web.

## Principe

Spécifier → Planifier → Développer localement → Tester → Git/GitHub → Pull Request → Gates → Fusion volontaire → Publication seulement si nécessaire.

Aucun hébergeur n'est imposé. Vercel intervient seulement si un accès distant est requis et si Vercel est adapté.

## Types

- `html-local`
- `pwa`
- `app-api`
- `dashboard`
- `backend`

Voir `PROJECT_TYPE_MATRIX.md`.

## Démarrage

1. Copier ce dossier dans un dépôt.
2. Compléter `PROJECT_PROFILE.yml`.
3. Compléter `SPEC.md`.
4. Exécuter `scripts/doctor.ps1` si le kit complet est utilisé localement.
5. Travailler dans une branche `feature/...`.
6. Tester localement.
7. Ouvrir une Pull Request.
8. Publier uniquement après décision explicite.
